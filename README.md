# CIG Event Media Management System

## Overview

The CIG Event Media Management System is a full-stack web application developed to centralize the management of event photos and videos. The platform enables administrators, photographers, and viewers to collaborate through role-based access control while leveraging cloud storage and AI-powered features.

## Features

* User Authentication and Authorization
* Role-Based Access Control
* Event Management (Create, Edit, Delete)
* Media Upload and Gallery Management
* Event-wise Album Organization
* Public and Private Media Visibility
* Likes and Favorites
* Comments System
* Notifications
* Analytics Dashboard
* AI-Based Auto Tag Generation
* Face Detection
* Dynamic Watermarking
* User Tagging

## Technology Stack

### Frontend

* React.js
* React Router
* Axios

### Backend

* Node.js
* Express.js

### Database

* MongoDB

### Cloud Services

* Cloudinary

### AI Integration

* Google Vision API

## System Architecture

Frontend (React.js) → Backend (Express.js) → MongoDB

Backend → Cloudinary

Backend → Google Vision API
